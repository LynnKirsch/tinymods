# Optima — Image Optimizer и HTML Content Editor

## Назначение

Два бесплатных браузерных инструмента без регистрации:

- **Image Optimizer** — подготовка изображений для сайта: кадр, размер без увеличения, сжатие и скачивание.
- **HTML Content Editor** — редактирование содержимого готовых HTML-блоков с общим Preview.

## Image Optimizer

Вход: JPEG/JPG, PNG, HEIC/HEIF, WebP и AVIF. JPEG — только входной формат.

| Режим | Выход |
| --- | --- |
| Фото | AVIF и WebP |
| Скриншот | AVIF, WebP и PNG |
| PNG с прозрачностью | Подготовленный PNG и PNG после OxiPNG |

Для AVIF/WebP доступны Q65, Q80 (по умолчанию), Q85 и своё целое значение 1–100. К PNG качество не применяется. PNG lossless означает отсутствие потерь при кодировании подготовленного растра, а не неизменность исходных пикселей после crop/resize.

Пользователь загружает до 10 изображений, выбирает кадр из оригинала, доступный размер и качество, запускает оптимизацию. Обработка последовательная. Лимиты: 40 МБ и 50 мегапикселей на файл; экспорт без увеличения. В общем batch-наборе учитывается самое маленькое изображение.

Настройки и готовые результаты принадлежат каждому изображению отдельно. Изменение настроек не заменяет готовые файлы до следующей успешной оптимизации. Ошибка новой обработки сохраняет предыдущий результат.

Для нового результата среди доступных AVIF/WebP по умолчанию выбирается самый лёгкий фактический файл. Пользователь может изменить выбор. Отмеченные результаты скачиваются отдельными файлами; браузер может запросить разрешение на несколько скачиваний.

## HTML Content Editor

- Вставка и загрузка кода через поле блока.
- Несколько блоков и несколько фрагментов одного блока.
- Общие Site CSS и Site JS, один Preview document.
- Редактирование обнаруженных текстов, ссылок, изображений, ALT, видео и постеров.
- Предпросмотр видео и копирование изменённого кода текущего блока.

Интерфейс не предоставляет сохранение и повторное открытие проектов. Рабочее состояние относится к текущему сеансу страницы; результат нужно скопировать перед уходом.

Preview выполняет пользовательские скрипты внутри изолированного iframe. HTML, CSS, изображения, видео и скрипты могут обращаться к внешним ресурсам. Изоляция не означает отсутствие сетевых запросов: используйте доверенный код.

## Приватность и ограничения

Изображения оптимизируются локально, без отправки исходников на сервер Optima. Аналитика Optima загружается после согласия; выбор cookie действует до 365 дней и доступен для изменения в политике. Уже отправленные данные не отзываются остановкой счётчика.

Необходим современный браузер с JavaScript и достаточной памятью. Нет аккаунтов, облачного хранения и публичного API. Экономия веса и точность визуального результата зависят от исходника и настроек.
