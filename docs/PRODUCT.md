# Умный оптимизатор изображений — MVP 0.1

## Цель продукта

Подобрать максимально лёгкий и подходящий формат и размер фотографии для
публикации на разных экранах сайта, сохраняя высокий уровень визуального
качества.

## Первый пользовательский сценарий

1. Пользователь загружает JPG, PNG, WebP или AVIF.
2. Выбирает назначение фотографии: первый экран, контент, галерея или карточка.
3. Выбирает высокий или максимальный порог качества.
4. Сервис создаёт адаптивные размеры и сравнивает AVIF, WebP и JPEG.
5. Для каждой ширины сервис отмечает самый лёгкий вариант, прошедший порог SSIM.
6. Пользователь скачивает отдельный файл или ZIP с форматами, размерами,
   `picture.html` и `manifest.json`.

## Критерии готовности MVP

- обработка происходит локально в браузере;
- исходная фотография никуда не отправляется;
- размеры зависят от места использования на сайте;
- сравниваются минимум AVIF, WebP и JPEG, когда исходник не содержит
  прозрачность;
- для каждого результата отображаются вес, формат и показатель сходства;
- скачивается готовый responsive-комплект;
- интерфейс работает на компьютере и телефоне;
- ошибка одного кодировщика не останавливает остальные форматы.

## Ограничения первой версии

- только одно изображение за расчёт;
- до 40 МБ и 50 мегапикселей;
- нет пакетной обработки, аккаунтов и облачного хранения;
- SSIM — автоматический ориентир, а не замена финальной визуальной проверке;
- GIF и анимированные изображения пока не поддерживаются.

## Следующий продуктовый этап

- пакетная обработка папки;
- умное определение назначения изображения по его пропорциям;
- более совершенная перцептивная метрика;
- сохранение фокусной точки для мобильного кадрирования;
- интеграция в админ-панели шаблонов сайтов;
- готовые плагины для Astro и WordPress.
