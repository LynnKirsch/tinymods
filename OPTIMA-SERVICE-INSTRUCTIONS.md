# Optima · Инструкции сервисов

Эти тексты предназначены для боковых панелей **«Инструкция»** на страницах сервисов Optima.

---

# Инструкция · Оптимизатор изображений

Оптима помогает подготовить изображения для сайта прямо в браузере: выбрать нужный формат, кадрировать изображение, задать размер и уменьшить вес файла без лишних действий.

Файлы обрабатываются локально в браузере. Изображения не отправляются на сервер.

## 1. Добавьте изображение

Перетащите файл в область загрузки или выберите его на компьютере.

Поддерживаются JPEG, PNG, HEIC/HEIF, WebP и AVIF: до 10 изображений, до 40 МБ каждое. JPEG используется только как входной формат.

Можно добавить несколько изображений и настроить каждое отдельно. Текущие настройки сохраняются для каждого кадра в очереди.

## 2. Выберите тип изображения

Оптима предлагает три режима:

**Фото** — для фотографий. Создаёт AVIF и WebP с выбранным качеством.

**Скриншот** — для интерфейсов, текста и схем. Создаёт AVIF, WebP и PNG без потерь.

**PNG с прозрачностью** — отдельный режим для PNG с прозрачным фоном. После подготовки размера можно скачать PNG без оптимизации. После нажатия «Оптимизировать» появляется скачивание оптимизированного PNG. Прозрачность сохраняется.

## 3. Подготовьте кадр

После загрузки откроется редактор кадрирования.

Выберите нужную пропорцию или оставьте исходную. Рамку можно двигать. Углы меняют размер пропорционально, боковые границы — только по одной оси.

Когда рамка приближается к центру изображения, появляются тонкие красные направляющие. Они помогают точно выровнять кадр по горизонтали и вертикали.

Когда композиция готова, сохраните кадр.

## 4. Выберите размер

Оптима показывает размеры, которые доступны для текущего кадра без увеличения исходного изображения.

Можно выбрать готовый вариант или указать свою ширину в поле **«Свой размер»**.

Оптима не растягивает маленькие изображения. Если после кадрирования доступно, например, 1254 px по ширине, итоговый файл нельзя увеличить больше 1254 px.

Если вы не уверены, какой размер нужен, откройте подсказку **«Как выбрать размер»** рядом с настройками.

## 5. Выберите качество

Для AVIF и WebP доступны готовые значения качества:

**65** — более лёгкий файл.

**80** — оптимальный вариант для большинства сайтов.

**85** — выше качество и немного больше вес.

**Своё** — целое значение от 1 до 100. При загрузке изображения в интерфейсе выбрано 85.

Для PNG используется оптимизация без потерь, поэтому качество в процентах для него не задаётся.

## 6. Запустите оптимизацию

Нажмите **«Оптимизировать»**.

Оптима обработает изображение в браузере и подготовит доступные варианты файлов.

Если вы работаете с несколькими изображениями, они обрабатываются последовательно.

## 7. Скачайте результат

После обработки появится раздел **«Готовые файлы»**.

Для нового результата автоматически отмечается самый лёгкий AVIF или WebP по фактическому размеру файла. Можно изменить выбор: отметить один формат, оба или снять отметки.

Для нескольких фотографий отметьте нужные фотографии и форматы. Готовые результаты скачиваются отдельными файлами; браузер может запросить разрешение на несколько скачиваний.

Если выбран один файл, кнопка скачивания покажет его размер и формат. Если выбрано несколько — можно скачать все выбранные файлы.

Для PNG будет указано **«Без потерь»**.

## Что важно помнить

Оптима не увеличивает изображения выше доступного размера исходного кадра.

Кадрирование выполняется до оптимизации, поэтому итоговый файл создаётся из выбранной области исходного изображения.

Для фотографий обычно стоит начать с качества 80. Если изображение должно быть особенно лёгким, попробуйте 65. Для крупных изображений и важных деталей можно использовать 85.

Если после изменения размера или кадра вы хотите получить новый вариант, снова запустите оптимизацию — предыдущий готовый результат останется доступен до успешного создания нового.

# Инструкция · Редактор HTML

Редактор HTML помогает менять тексты, ссылки, изображения и другие данные в готовом HTML-блоке без ручного поиска нужных мест в коде.

Слева находится содержимое блока, справа — его предпросмотр. Вы меняете данные в полях и сразу видите результат.

## 1. Загрузите код блока

Добавьте HTML-код блока в поле **«Код для блока»**.

Код можно загружать целиком. Редактор сам определяет HTML, CSS и JavaScript внутри блока и собирает их для предпросмотра.

Если один логический блок состоит из нескольких частей кода, используйте **«Добавить код к блоку»**.

Если на странице несколько отдельных блоков, используйте **«Добавить блок»**.

Загружайте блоки в том порядке, в котором они расположены на странице.

## 2. Не забывайте про JavaScript

Для обычного статичного блока иногда достаточно HTML и CSS.

Но если в блоке есть слайдер, вкладки, аккордеон, мобильное меню, модальное окно, видео, кнопки с интерактивным поведением, переключатели или другая логика, нужно загрузить и JavaScript этого блока.

Если загрузить только HTML и CSS, блок может выглядеть правильно, но слайдер, кнопки или другие интерактивные элементы не будут работать.

Поэтому для сложных блоков всегда проверяйте, есть ли у них отдельный JS-код.

## 3. Что такое общие стили сайта

Некоторые стили относятся не к одному конкретному блоку, а сразу ко всему сайту или странице.

Например: общие шрифты, CSS-переменные, базовые цвета, стили контейнеров, общие отступы, reset-правила, общие классы кнопок и стили, которые используются сразу в нескольких блоках.

Такой код нужно загружать отдельно в область **«Общие стили сайта»**.

### Где найти общие стили в Tilda

В Tilda общие пользовательские CSS-стили часто находятся в разделе:

**Настройки сайта → Ещё → Вставка кода → Пользовательские стили**

или в аналогичном поле с CSS-кодом страницы/сайта.

Если блок в редакторе выглядит не так, как на опубликованном сайте, одна из самых частых причин — не загружены общие стили.

## 4. Что такое общий JavaScript сайта

Так же, как CSS, JavaScript может относиться не к одному блоку, а к странице или сайту целиком.

Например, общий JS может запускать слайдеры, связывать несколько блоков, управлять меню, открывать модальные окна, добавлять поведение при прокрутке или инициализировать сторонние элементы.

Такой код загружается отдельно в область **«Общий JS сайта»**.

Если интерактивный элемент не работает в предпросмотре, проверьте, не находится ли его JavaScript в общем коде сайта.

## 5. Сохраняйте порядок кода

Порядок имеет значение.

Если на реальной странице сначала подключаются одни стили, а затем другие, более поздние правила могут переопределять предыдущие.

Поэтому блоки и их части лучше загружать в том же порядке, в котором они находятся в исходной странице.

Это особенно важно, если несколько CSS-фрагментов изменяют одни и те же элементы.

## 6. Редактируйте содержимое слева

После загрузки кода редактор найдёт доступные для изменения данные и покажет их в панели **«Содержимое»**.

Можно менять заголовки и обычный текст, ссылки, изображения, ALT-тексты, содержимое слайдеров и других распознанных групп, а также другие поддерживаемые данные блока.

Клик по редактируемому элементу в предпросмотре помогает перейти к соответствующему полю слева.

## 7. Предпросмотр справа

Справа отображается готовая композиция из всех загруженных блоков.

Верхние размеры позволяют проверить страницу на разных ширинах: от телефона до Full HD.

Предпросмотр показывает страницу в выбранной ширине, а затем уменьшает её только визуально, чтобы она помещалась в рабочей области.

Это значит, что адаптивные правила блока проверяются на настоящей выбранной ширине, а не на уменьшенной ширине окна редактора.

## 8. Слайдеры

Если блок содержит слайдер, обязательно загрузите весь код, который нужен для его работы:

**HTML + CSS + JavaScript.**

HTML создаёт структуру слайдов.

CSS отвечает за размеры, расположение и внешний вид.

JavaScript отвечает за переключение, прокрутку, стрелки, активный слайд и другое интерактивное поведение.

Если JavaScript находится отдельно от HTML-блока, добавьте его как дополнительный фрагмент блока или как общий JS сайта — в зависимости от того, как он подключён на исходной странице.

В предпросмотре редактор может показывать собственные стрелки для удобного переключения слайдов. Они относятся только к интерфейсу редактора и не добавляются в ваш исходный код.

## 9. Блокировка общих стилей и скриптов

Общие стили и общий JavaScript можно закрепить.

Закреплённый код продолжает участвовать в предпросмотре при работе с другими блоками.

Это удобно, если вы последовательно редактируете несколько блоков одной страницы, которые используют одну и ту же общую CSS- или JS-базу.

## 10. Сброс и копирование кода

Кнопка **«Сбросить»** возвращает блок к исходному состоянию.

Если код блока был изменён, появляется кнопка **«Скопировать код блока»**.

Она копирует текущую версию блока с вашими изменениями.

Если вы вернули все значения к исходным, блок снова считается неизменённым.

## Если предпросмотр отличается от сайта

Проверьте по порядку:

1. Загружен ли весь HTML блока.
2. Загружен ли CSS блока.
3. Загружен ли JavaScript, если блок интерактивный.
4. Добавлены ли общие стили сайта.
5. Добавлен ли общий JavaScript сайта.
6. Сохранён ли исходный порядок подключения кода.

Чаще всего различие связано не с самим редактором, а с тем, что в предпросмотр не был добавлен один из внешних CSS- или JS-фрагментов, от которого зависит блок.
